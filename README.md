# Ninjago 3D (fan game)
Unofficial fan project. Not affiliated with LEGO. Do not sell.

## Add to Home Screen
- iPhone: open the link in Safari -> Share -> Add to Home Screen.
- Android: Chrome -> menu (3 dots) -> Install app / Add to Home screen.
- PC: Chrome/Edge -> Install icon in the address bar.

After the first load the game is cached, so it can open offline.
Settings and saves are stored on the device (localStorage).
